開いた瞬間から、
読める Markdown。

Markdown ファイルは、そのまま開くと記号の混じったテキストのままです。Markdown Viewer & Editor は、それを見出しや表の整った文書として表示します。直したいところは、その場で手早く直せます。

App Store 審査中
# 見出し **太字** - [x] タスク | 表 | ``` コード > 引用 [リンク](…) ![画像](…)

手元にあるのに、読めない。

README、設計メモ、日報、AI に書かせた .md。ファイルはそこにあるのに、開くと記号の並んだテキストが出てくるだけ。Markdown Viewer & Editor は、この状態を解くために作りました。

開いたその場で、文書として

見出し、リスト、チェックボックス、表、コード。GitHub Flavored Markdown を、ファイルを開いたその場で組み上げて表示します。取り込みの手順も、変換の待ち時間もありません。

  • iCloud Drive でも、ほかのファイル提供元でも、置いてある場所のまま開きます
  • 生の HTML は実行せず、書いてあるとおりの文字として出します

チェックは、タップひとつで

タスクリストは、編集に入らなくてもタップで切り替わります。書き換わるのは、原文の [ ] と [x] の 1 文字だけです。

  • 表は横にスクロールし、列ごとの寄せも再現します
  • コードブロックには言語のラベルとコピーのボタンが付き、Swift や Python、JavaScript などに色を付けます
  • URL で書かれた画像を表示します。タップで画面いっぱいに開き、ピンチで寄れます

直すのは、その場で

鉛筆のボタンか、本文の長押しで編集に入ります。長押しなら、押した段落の頭にカーソルが立ちます。直すのは素の Markdown です。

  • 等幅で表示し、見出し・強調・コード・リンク・リスト記号に色を付けます
  • キーボードの上に、見出し・太字・斜体・リンク・画像・コード・リスト・タスク・引用・字下げ・取り消しとやり直しのボタン
  • リストの行で改行すると次の記号が入り、空の項目で改行すると外れます
  • 保存は自動です。プレビューに戻っても、見ていた場所のままです

長い文書でも、迷わない

見出しから目次を自動で作り、タップでその場所へ飛べます。文書内の検索は、大文字小文字・濁点・全角半角の違いを無視して探します。

  • 一致した箇所すべてに色が付き、いま選んでいる 1 件だけが濃くなります
  • 大きな文書でも、解析は裏で進むので操作が止まりません

自分の目に合わせる

書体はゴシックと明朝から。文字の大きさと行間を変えられ、端末の文字サイズ設定にもかけ合わさります。

  • テーマはシステムに合わせる・ライト・ダーク・セピアの 4 つ
  • PDF に書き出すときも、書体・文字の大きさ・行間はこの設定のとおりです
  • Markdown の原文は、そのまま共有できます

iPad では、並べて読む

ステージマネージャや Split View で、複数の文書を並べて開けます。画面が広くても、1 行が長くなりすぎないよう読みやすい幅で折り返します。

  • 外付けキーボードでは ⌘⇧P でプレビューと編集の切り替え、⌘F で検索、⌘⇧T で目次
  • 編集中は ⌘B で太字、⌘I で斜体、⌘K でリンク

このアプリが守っていること

凝った機能より先に、ファイルを壊さないことを決めました。

ファイルは借り物として扱います

ファイルを取り込みません。置いてある場所のまま開いて、直して、返します。

  • アプリの中に独自のデータベースを持たないので、インポートも、独自のクラウド同期も、二重管理もありません
  • 使うのをやめても、ファイルはそこに残ります

書いた通りに保存します

読み込んで保存し直しても、触っていない行はバイト単位で変わりません。

  • 改行コードの変換も、行末の空白の除去も、リスト記号の統一もしません。よかれと思った整形は、Git の差分を汚し、ほかのアプリとの共存を壊すためです
  • 引用符やハイフンの自動変換も切ってあります

日本語の文書のために

日本語の文書で効く判断を 2 つ入れています。

  • 折り返して書いた行をつなぐとき、語間に空白を入れません。前後がどちらも日本語のときだけ詰めます
  • 小さな図版を画面幅まで引き伸ばしません。原寸を上限にするので、アイコンや小さな図がぼやけません

食い違ったら、選べます

同じファイルがほかの端末やほかのアプリで同時に変更されると、どちらを残すかを選ぶ画面が出ます。

  • 保存した端末の名前、更新時刻、中身の冒頭が並ぶので、見比べてから決められます

あなたのファイルは、
開発者に届きません。

アカウントも、サーバーも、解析もありません。ネットワークを使うのは、文書の中の画像を表示するときと、あなたがリンクを開いたときだけです。

アカウントも、サーバーもない

登録もログインもありません。開発者が運用するサーバーは存在しません。

ファイルを預からない

開いたファイルは、置いてある場所で読み書きするだけです。アプリの中にも、開発者の手元にも、コピーは作りません。

画像は、書かれた URL から

文書が URL で画像を指しているときだけ、その画像を取りに行きます。取りに行く先は文書に書かれた場所で、開発者ではありません。

リンクは、Safari の画面で

タップしたリンクは、アプリの中に開く Safari の画面で表示します。そのページの中身を、アプリは見られません。

写真ライブラリを読まない

画像を入れるときは iOS の写真選択画面を使うので、ライブラリの読み取り許可を求めません。渡るのは、選んだ写真だけです。

広告も、トラッキングもない

解析 SDK・広告 SDK は入っていません。App Store の「App のプライバシー」でも、データを収集しないと申告しています。

詳しくはプライバシーポリシーをご覧ください。
